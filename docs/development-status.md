# Development status

This repository is an initial working foundation, not a production-ready or complete MVP. The app has an organization-scoped API, JWT authentication and registration endpoints, document/version upload, queued PDF/DOCX/XLSX/CSV/text parsers, source-located unverified evidence, evidence verification, heuristic questionnaire import for PDF/DOCX/XLSX/CSV/text, a normalized XLSX export, cited answer drafts, citation-required approval, audit and approval events, and a live React workspace. OpenAI Responses is available as a configured provider; provider calls persist usage/latency metadata but not raw prompts or responses. The default deterministic provider is for development only.

The following requested capabilities remain unfinished and must not be represented as working: organization/user administration and invitations; email verification and password reset delivery; Anthropic provider; vector embeddings and semantic/hybrid retrieval (the current retrieval uses keyword overlap); claim extraction/normalization and conflict/freshness workflows; comprehensive commitment analysis (current check is a conservative phrase rule); editable answer revisions; team routing and review assignment UI; DOCX/CSV/PDF export; original questionnaire layout preservation; notifications; S3 storage; billing; API rate limits; detailed retention/soft deletion; production observability; and full end-to-end workflow coverage.

The mock provider is deterministic and abstains without a keyword-matched verified source; it is intended only for development. OpenAI Responses requires an explicitly configured API key and model, and sends the question plus retrieved evidence excerpts to that endpoint. Uploaded files are stored locally by default. Docker is required to run the compose stack and is not available in all environments. Authentication, parsing, exports, provider calls, and migrations have not been runtime-tested in this environment because Django/frontend dependencies could not be installed under the network restriction.
